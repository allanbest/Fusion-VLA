# Engine documents

Copied unchanged (except crate paths) from the main Fusion repository at
commit `1a03b12`. They describe Fusion Core as a whole. Links to documents,
benchmarks or crates that were not extracted (the Standard engine,
`fusion-sim`, the editor) point at files that only exist in the main repo.

Start with [FUSION_CORE_ENGINE.md](FUSION_CORE_ENGINE.md), then
[CORE_ENGINE_STATUS.md](CORE_ENGINE_STATUS.md) for what is implemented.
For the Python / training interface, read [HANDOFF.md](HANDOFF.md).
